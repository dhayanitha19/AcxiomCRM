Sign in

POST /api/auth/login
Content-Type: application/json

{"email":"person@example.com","password":"your-password"}

The response includes a CSRF token for subsequent write requests. The password and hash are never returned.

Create a customer

POST /api/customers
Content-Type: application/json
X-CSRF-Token: <csrf_token>

{"name":"Example Co","email":"contact@example.com",
 "phone":"+91 98765 43210","status":"Active",
 "owner_id":1}

Success returns 201. Invalid data returns 400; duplicates return 409; unauthenticated calls return 401.

Response shape

{"item":{"id":12,"name":"Example Co","email":"contact@example.com", "phone":"+91 98765 43210"}}

Lists return {"items": [...], "count": 0}. Database internals and password fields are excluded.
